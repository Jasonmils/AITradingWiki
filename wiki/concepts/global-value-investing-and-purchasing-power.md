# 全球价值投资与购买力框架

## 问题与范围

这一框架回答两个相连的问题：如何在全球范围内寻找长期可持有的企业所有权，以及如何用真实购买力而不是名义货币金额衡量长期财富。它来自[[li-lu|李录]] 2024-12-07 演讲的第三方转载稿，属于来源驱动的投资方法论，不是经回测认证的交易系统。

## 六项原则

| 原则 | 研究动作 | 常见误用 |
|---|---|---|
| 企业所有权 | 研究商业模式、治理、竞争优势与长期现金创造 | 把股票只当价格代码 |
| “市场先生” | 把报价当作可选择的交易条件 | 用短期涨跌替代价值判断 |
| 安全边际 | 对内在价值使用保守假设并要求价格折让 | 把模糊的“便宜”当安全边际 |
| 优质企业与能力圈 | 只在可理解范围内评价长期质量 | 用知名度或行业热度替代可理解性 |
| 到鱼多之处捕鱼 | 在全球范围比较机会集 | 忽略上市制度、币种、税务与治理差异 |
| 有活力的经济与企业 | 关注长期价值创造的制度与公司基础 | 从宏观增长直接推出个股回报 |

## 宏观与微观

框架并不否认宏观变量，而是把可操作性放在微观层面：

> 宏观环境与制度 → 行业结构 → 企业竞争优势 → 收入与现金流 → 证券权利 → 估值与价格

宏观环境影响机会集和风险，但企业研究、证券条款与买入价格仍需独立判断。跨市场应用时，还必须区分上市制度、发行人注册地、会计准则、报告/交易币种、政策辖区和汇率。

## 购买力视角

名义财富是货币单位，经济财富则可理解为未来商品与服务的购买力份额。实际应用至少需要：

1. 明确投资期限和负债币种；
2. 估计税后、费用后名义回报；
3. 选择与投资者消费篮子相匹配的购买力基准；
4. 评估企业能否通过定价权、生产率和再投资维持实际现金流；
5. 比较替代机会，而不是只比较历史成本。

这一定义不等于“任何实物或股票都能抗通胀”，也不能省略估值。

## 卖出纪律与杠杆约束

来源提出三类主要卖出条件：投资判断被证明错误；出现显著更好的机会；价格达到极端高估。避免杠杆的理由，是防止融资约束和强制平仓使长期判断无法实现。

该纪律仍需落到可检查的失效条件、机会成本、税费、流动性和组合风险，不能只凭主观确信执行。

## 研究与投资桥

对具体证券应用时，至少依次回答：

1. 企业是否在能力圈内，竞争优势和治理是否可验证？
2. 收入、利润与 FCF 是否可持续，增长是否需要过度资本投入？
3. 上市证券拥有什么权利，是否存在稀释、负债、少数股东或跨市场差异？
4. 保守内在价值区间、假设和敏感性是什么？
5. 当前价格是否提供足够安全边际？
6. 哪些证据将使论点失效，何时复核？

“行业值得研究”和“当前价格值得交易”必须分别回答。

## 证据缺口与失效边界

- 来源是第三方转载稿，原则表述未与官方录音或讲稿逐句核验。
- 演讲中的中国消费、储蓄、就业和制造业数字缺少年份与统一定义，不能作为本框架的事实前提。
- 本页未建立内在价值计算、购买力指数或回测 Model。
- 框架无法保证超额回报；若企业判断、证券权利或估值输入错误，方法论标签不能消除损失。
