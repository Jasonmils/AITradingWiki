# 资产负债表衰退

## 定义

资产负债表衰退（Balance Sheet Recession）是一个解释私人部门在资产价格大幅下跌后，优先修复资产负债表而不是追求新增利润或支出的宏观框架。

典型链条为：

> 资产价格下跌 → 净资产缩水但债务名义值刚性 → 家庭或企业增加储蓄、偿还债务 → 借款、消费和投资下降 → 银行信贷需求与信用创造走弱 → 总需求持续不足

这一框架解释的是部门行为和宏观传导，不是只要房地产或股票下跌就必然出现的机械定律。

## 核心机制

### 1. 资产和债务的非对称变化

房地产、股票、土地或其他抵押品价格可以快速下跌，但贷款本金不会同步下降。即使现金流尚未立即恶化，借款人的净资产和抵押能力也可能显著下降。

### 2. 行为目标发生变化

正常扩张期，家庭和企业可能比较预期回报率与融资成本；资产负债表受损后，目标可能转为降低杠杆、补充流动性和避免破产。此时即便利率下降，新增借款需求也可能不足。

### 3. 个体理性形成总体收缩

单个主体偿债和储蓄是理性行为，但大量主体同时这样做，会降低销售、收入、投资和就业，进而使其他主体更难修复资产负债表。

### 4. 信贷供需同时受约束

- 借款人可能因为前景恶化和去杠杆而不愿借款；
- 银行可能因为不良资产、资本约束和抵押品缩水而不愿放贷；
- 两者可以同时发生，但必须用不同证据识别。

## 与相近概念的区别

| 概念 | 主要约束 | 典型信号 | 不能混同之处 |
|---|---|---|---|
| 普通周期性衰退 | 需求、库存或政策周期 | 利率下降后需求通常逐步恢复 | 不一定伴随系统性去杠杆 |
| 资产负债表衰退 | 私人部门优先偿债和修复净资产 | 低利率下借款与投资仍疲弱 | 重点是借款需求和部门目标变化 |
| 银行危机/信贷紧缩 | 银行资本、流动性或资产质量约束 | 贷款标准收紧、信贷供给下降 | 可以没有广泛私人部门偿债意愿 |
| 债务通缩 | 价格下跌提高实际债务负担 | 通缩、违约和资产抛售相互强化 | 更强调价格水平和实际债务反馈 |
| 流动性陷阱 | 名义利率接近下限、货币需求高 | 传统降息传导弱 | 不要求私人资产负债表已严重受损 |

现实中这些机制可以重叠，研究时应分别验证。

## 部门分解

| 部门 | 需要观察的资产负债表 | 关键行为指标 |
|---|---|---|
| 家庭 | 房产、金融资产、按揭和消费贷 | 储蓄率、按揭提前偿还、住房成交、耐用品消费 |
| 非金融企业 | 土地/设备/金融资产、银行贷款和债券 | 净借款、资本开支、现金持有、债务偿还、产能利用率 |
| 房地产开发商 | 土地储备、在建项目、预售款、债务 | 开工、竣工、拿地、销售回款、债务展期与违约 |
| 银行 | 贷款、抵押品、不良资产、资本 | 信贷标准、不良率、拨备、资本充足率、净息差 |
| 政府 | 财政资产、债务和或有负债 | 财政赤字、转移支付、公共投资、地方融资约束 |
| 外部部门 | 经常账户、外币资产和负债 | 净出口、资本流、外币债务、汇率敏感性 |

“整个国家都在去杠杆”通常过于笼统。必须识别哪个部门负债、谁持有资产、损失由谁承担，以及其他部门是否加杠杆对冲。

## 最低证据清单

在认定一个经济体进入资产负债表衰退前，至少核验：

1. 资产价格是否发生广泛且持续的下跌，而非短期波动；
2. 哪个私人部门的净资产显著恶化；
3. 债务偿还、储蓄上升或净借款下降是否得到流量数据支持；
4. 信贷疲弱主要来自需求、供给还是两者共同作用；
5. 利率下降后消费、投资和借款是否仍缺乏弹性；
6. 银行资产质量和资本约束是否放大收缩；
7. 政府、外部部门或其他私人部门是否通过扩表抵消需求缺口；
8. 人口、生产率、汇率和产业结构是否形成独立拖累。

缺少这些证据时，只能说“存在资产负债表衰退风险”或“该框架具有解释力”，不能把框架写成已确认结论。

## 日本经验

欧洲央行和 BIS 对日本等经济体的讨论支持以下机制：

- 资产价格下跌后，过度负债部门会进行多年去杠杆；
- 日本案例的主要去杠杆主体更偏向非金融企业；
- 美国全球金融危机后的主要修复主体更偏向家庭；
- 低利率并不保证私人部门立即恢复借款；
- 银行损失确认、财政反应和结构性因素会影响持续时间。

这支持“部门资产负债表受损可以造成长期需求不足”，但不证明日本停滞只有一个原因。

## 中国与日本类比的边界

[[2026-06-02-rise-and-fall-lessons-from-japan|来源课程]]把中国 2023 年以来的房地产调整与日本泡沫破裂相联系。这一比较属于 `source_opinion`，研究时至少要区分：

- 债务主要集中在家庭、开发商、地方政府还是国有企业；
- 土地制度、预售制度和住房金融结构；
- 银行所有制、坏账确认和资本补充机制；
- 资本账户、汇率制度和经常账户；
- 人口年龄、城镇化阶段和住房存量；
- 财政中央—地方关系；
- 制造业竞争力、全球贸易份额和外部需求；
- 政策反应速度、转移支付和社会保障体系。

相似的房价下跌不等于相同的损失分配、信用收缩或增长路径。

## 政策传导边界

在私人部门去杠杆期间，不同政策工具作用不同：

- 降息和流动性工具可以降低利息负担，但未必创造借款需求；
- 银行资本重组可以修复供给，但不能替代借款人修复净资产；
- 财政支出可以填补部分需求缺口，但效果取决于规模、乘数、融资和退出机制；
- 债务重组、损失确认和资产处置可能加快修复，但会重新分配损失；
- 结构改革可能提高长期生产率，但短期可能无法抵消去杠杆。

“需要财政扩张”或“货币政策无效”都不能脱离部门数据和政策规模直接下结论。

## 投资研究传导

资产负债表衰退风险需要沿以下路径进入投资判断：

> 部门去杠杆 → 信贷与名义需求 → 行业销量和定价 → 企业收入、利润与现金流 → 违约与资本回报 → 利率、汇率和风险溢价 → 当前估值与可交易性

可能受影响的方向包括：

- 银行：贷款需求、资产质量、净息差和资本；
- 房地产及建材：成交、开工、库存和现金回款；
- 可选消费：财富效应、耐用品与高杠杆家庭支出；
- 出口制造：内需疲弱可能由外需部分对冲，也可能面临汇率压力；
- 政府相关行业：财政扩张可能形成订单，但需验证付款和现金流；
- 债券与汇率：增长和通胀下降不必然带来单向价格变化，仍取决于政策、供给和风险溢价。

宏观框架成立，不等于某一行业或证券在当前价格值得交易。

## 跟踪指标

- 部门资金流量表、净借款和债务偿还。
- 房价、土地价格、股票和抵押品估值。
- 家庭储蓄率、消费信贷和按揭提前偿还。
- 企业资本开支、现金余额、债务期限和利息覆盖。
- 银行贷款需求调查、审批标准、不良率和拨备。
- 名义 GDP、核心通胀、工资、失业和产能利用率。
- 财政赤字、中央和地方支出、转移支付与政府债务。
- 经常账户、净出口、资本流和汇率。

## 证据缺口与失效条件

- 本页尚未建立日本、中国和美国的统一部门资产负债表数据库。
- “资产负债表衰退”不是完整增长模型，不能替代人口、生产率、政策、贸易和产业结构分析。
- 若私人借款、消费和投资在资产价格下跌后迅速恢复，或资产负债表修复并非需求疲弱的主要解释，应降低该框架权重。
- 形成市场或证券判断前，必须重新核验最新部门数据、政策、财报、估值和上市地交易规则。
