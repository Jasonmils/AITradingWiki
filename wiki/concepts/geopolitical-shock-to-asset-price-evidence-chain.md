# 地缘政治冲击到资产价格的证据链

## 定义

本框架用于防止把战争、制裁、政变、航道受阻或联盟变化直接等同为某类资产的涨跌结论。

完整链条为：

> 地缘政治事件 → 物理供应与运输 → 现货、库存、运费与保险 → 通胀和政策反应 → 行业收入与成本 → 公司利润与现金流 → 当前估值、仓位与可交易性

每一层都必须有独立证据。前一层真实，不代表下一层必然成立。

## 七层证据链

| 层级 | 需要回答的问题 | 优先证据 | 常见错误 |
|---|---|---|---|
| 1. 事件 | 谁在何时采取了什么行动，事件是否仍在持续？ | 政府、多边机构、监管文件、卫星或航运记录 | 把交战方声明或社交媒体传闻当作完整事实 |
| 2. 物理供应 | 产量、出口、管线、港口、海峡和替代路线实际变化多少？ | 产量、船舶流量、港口、管线、停产和库存数据 | 从“发生战争”直接推出“供应必然减少” |
| 3. 市场微观结构 | 现货、期限结构、裂解价差、运费、保险和库存如何变化？ | 现货/期货、time spread、库存、运费和 war-risk premium | 只看新闻标题或单一主力合约 |
| 4. 宏观反应 | 冲击是一次性价格变化还是持续通胀？政策如何响应？ | CPI/PPI、通胀预期、利率、财政补贴和储备释放 | 把名义价格上涨等同于企业实际需求增强 |
| 5. 行业传导 | 哪些行业获得收入，哪些行业承受原料、运输和需求压力？ | 供需平衡、合同定价、成本结构、替代关系 | 只列“受益板块”，不计算净影响 |
| 6. 公司财务 | 暴露能否转化为销量、价格、利润和现金流？ | 公司披露、订单、交付、利润率、营运资本和 FCF | 用行业主题替代公司产品、客户和合同证据 |
| 7. 交易性 | 当前价格计入多少预期，风险收益是否仍有吸引力？ | 现价、估值、隐含预期、期权、仓位和催化剂 | “行业值得研究”直接跳到“股票值得买” |

## 第一层：事件必须先做口径分离

地缘事件通常至少存在四种不同口径：

1. 交战方 A 的行动和法律解释；
2. 交战方 B 的行动和法律解释；
3. 第三国或多边机构记录；
4. 可观测的物理结果。

处理规则：

- 明确日期、地点、行动主体和对象；
- 对“自卫”“侵略”“封锁”“开放”等法律或政治措辞保留出处；
- 不以一方正式声明自动否定另一方的事实陈述；
- 优先寻找能够被外部测量的船舶、产量、港口、卫星和价格数据。

正式声明可以证明“一方这样宣称”，但未必证明声明中的因果、责任和法律评价。

## 第二层：物理约束比宏大叙事更接近价格

能源市场首先需要量化：

- 受影响产量和出口量；
- 中断持续时间；
- 库存和战略储备；
- 闲置产能；
- 管线、港口和替代航线；
- 炼厂和终端对原料的可替代性；
- 运输、保险和融资是否仍可用。

以霍尔木兹海峡为例，EIA 估计 2025 年上半年约 20.9 million b/d 石油流经该海峡，约相当于全球石油液体消费的 20%；沙特和阿联酋可绕开海峡的主要管线能力合计约 4.7 million b/d。由此可以确认海峡重要，但不能推出所有流量都会永久中断。

## 第三层：区分风险溢价与真实短缺

需要同时观察：

- 现货价格和近远月价差；
- 商业库存和浮仓；
- tanker rate、war-risk insurance 和融资条件；
- 出口品级折价与区域价差；
- 炼厂开工、裂解价差和成品油库存；
- 船舶是否绕行、延迟、停航或更换旗国。

价格上涨可能来自：

- 已发生的物理短缺；
- 对未来短缺的风险溢价；
- 被迫补库存；
- 制裁和结算摩擦；
- 投机仓位。

这些来源的持续时间和公司盈利影响不同。

## 第四层：宏观与政策会形成反馈

能源冲击可能通过以下路径影响宏观：

> 能源/运输成本 → 商品与服务价格 → 通胀预期 → 实际收入和需求 → 货币政策/财政补贴 → 汇率和融资条件

但政策会改变原始冲击：

- 释放战略储备；
- 调整制裁和贸易规则；
- 补贴居民或企业；
- 降低燃油税或实施价格管制；
- 组织护航、修复设施或开放替代运输；
- 通过需求破坏压低后续价格。

因此，“油价上涨导致长期通胀”只是待验证假设。

## 第五至第六层：从行业映射到公司财务

公司层面至少需要回答：

- 公司是生产商、贸易商、运输商、炼化商、消费方还是设备供应商？
- 产品定价是现货、长协、成本加成还是受监管价格？
- 收入增加是否伴随采购、运输、保险、税收或营运资本成本上升？
- 公司能否实际交付，还是产能、港口或制裁同样受限？
- 对冲合约会延迟还是抵消价格影响？
- 盈利增加是否能转化为自由现金流并归属于上市公司股东？

同一油价冲击可能同时：

- 提高上游收入；
- 压缩炼化或化工价差；
- 增加航空、航运、制造和居民成本；
- 触发需求下降；
- 推高工作资本占用。

不能只记录收入方向。

## 第七层：行业吸引力不等于当前可交易性

完成财务映射后仍需核验：

- 当前股价和估值日期；
- 市场隐含的商品价格和盈利假设；
- 一致预期是否已经上修；
- 期权隐含波动率和尾部保护成本；
- 仓位、拥挤度和政策反转风险；
- 催化剂、时间窗口和失效条件。

即使地缘风险长期存在，也可能因为估值过高、预期充分或需求破坏而不具备正向风险收益。

## 证据分类

| 情形 | 建议证据类型 |
|---|---|
| 政府、多边机构或可复核数据确认的行动和流量 | `verified_fact` |
| 政府、军队或公司对自身行动、目标和能力的陈述 | `company_statement` 不适用于主权政府；在正文中标注“官方声明”，并只确认其发布行为 |
| 评论员对国家意图、联盟和长期秩序的判断 | `source_opinion` |
| 多数研究机构或市场定价共同反映的基准 | `market_consensus` |
| 与主流不同、且给出可验证条件的判断 | `non_consensus` |
| 秘密协作、未公开命令或内幕动机 | `market_rumor` |
| 情景中的产量、时间、概率、弹性和估值输入 | `model_assumption` |
| Codex 对多层数据的机制归纳 | `codex_inference` |
| 日期、数量、状态或归因存在实质冲突 | `disputed` |

由于现有 canonical enum 没有单列“政府声明”，主权政府的正式声明应在论断文字中明确“某政府宣布/声称”，避免把其自述动机误记为已经独立验证的事实。

## 霍尔木兹海峡案例

[[2026-02-28-us-israel-iran-conflict-and-hormuz-crisis|2026 年霍尔木兹海峡危机]]说明：

- 战争和航行受阻是真实事件；
- EIA 数据显示 2026 年一季度海峡石油流量降至约 14.6 million b/d，低于 2025 年一季度约 20.4 million b/d；
- 伊朗、美国、海湾国家和联合国对“封锁”“开放”“航行权”和责任存在不同口径；
- 阿联酋退出 OPEC 改变了产油国协调框架，但不自动决定其产量路径；
- 必须继续追踪流量、闲置产能、库存、油价曲线和政策反应。

该案例支持“地缘冲击值得提高能源研究优先级”，不支持“油价或任何证券只会上涨”。

## 不应机械采用的规则

- 战争发生 → 油价必涨；
- 海峡受阻 → 所有能源公司受益；
- 产油国联盟变化 → 产量立即最大化；
- 通胀上升 → 所有资源股上涨；
- 国家实力上升 → 该国资产回报上升；
- 国际秩序变化 → 某一市场必然获得最大红利；
- 长期主题正确 → 当前价格值得交易。

## Model 与 Synthesis 边界

本 Concept 只定义证据传导，不填入情景概率和价格预测。

只有取得下列输入后，才适合创建 Model：

- 明确的冲突持续期情景；
- 产量和运输损失；
- 库存、闲置产能和替代路线；
- 需求弹性、政策反应和价格路径；
- 公司产销、成本、税率、营运资本和资本开支；
- 估值起点和折现假设。

只有完成多来源比较、公司暴露、估值和当前价格核验后，才适合创建 Synthesis 或当前交易判断。
