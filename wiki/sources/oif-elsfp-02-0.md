# OIF ELSFP Implementation Agreement 02.0

## 来源元数据

- 来源类型：行业 Implementation Agreement；规范性互操作文件
- 发布机构：OIF
- 文档版本：02.0

## 摘要

ELSFP 02.0 定义外置激光源模块的 form factor、热、电气、光学和 CMIS 管理接口，目的是使外置激光源可以互操作、可维护。规范不规定具体供应商份额或市场规模。
