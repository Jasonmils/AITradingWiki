# OIF 3.2Tb/s CPO Module Implementation Agreement 01.0

## 来源元数据

- 来源类型：行业 Implementation Agreement；规范性互操作文件
- 发布机构：OIF
- 文档版本：01.0
- 知识截止日：2023-03-30
- 原始文件：`raw/oif-co-packaging-3.2t-module-01.0.pdf`

## 摘要

该 Implementation Agreement 定义 3.2Tb/s CPO module 的机械、电气、光学和管理接口，包含 8×400G DR4/FR4 光接口与 32×106.25Gb/s 电接口。它用于互操作，不证明任何供应商产品已获认证或量产。
