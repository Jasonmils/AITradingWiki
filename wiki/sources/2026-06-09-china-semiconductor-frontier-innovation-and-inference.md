## 从国产替代到前沿创新

课程将五项变化连接为一条叙事：

> AI 需求增长 → 全球与中国半导体销售上升 → 中国 IC 出口增长 → 资本和政策支持 → 芯片与系统技术创新 → 产业链由追赶进入前沿竞争

这条链可以提出研究假设，但不能压缩中间证据：

1. 全球销售增长不等于中国企业份额增长；
2. 出口金额增长不等于高端产品数量或单位价值必然提升；
3. 注册资本不等于基金已经投资；
4. 公司发布技术原则不等于产品、良率、客户和财务效果已经兑现；
5. 系统峰值指标不等于特定工作负载的有效 Token 成本；
6. 产业进步不等于任一上市证券在当前价格具有回报空间。

课程按设计、制造、材料、设备、封测、EDA/IP 和存储展示了中外差距。该分层框架有检索价值，但部分图表来自 2020 年 Bain 数据或未显示完整来源，不能作为 2026 年实时市场份额使用。

## 韬定律与系统级计算

本次创建：

- [[2026-05-25-huawei-presents-tau-scaling-law|华为发布韬（τ）定律（2026-05-25）]]
- [[ai-compute-system-performance-and-token-economics|AI 算力的系统级性能与 Token 经济性]]

华为把韬（τ）定律描述为以“时间缩微”替代单纯的几何缩微，通过 LogicFolding、软件/架构/芯片协同和灵衢总线等降低信号传播与系统通信时延。发布和公司表述可以记录，但不能把“定律”名称本身视为独立同行评审确认，也不能把未来等效密度直接当作已经量产的工艺节点。

课程用 Ascend 910C 与 NVIDIA GB200 的单卡差距、CloudMatrix 384 与 NVL72 的集群差距，说明系统设计可能弥补单芯片不足。研究时应至少同时记录：

- 数值精度和稀疏性；
- 芯片/NPU/GPU 数量与互联拓扑；
- HBM/片上内存容量、带宽和 KV cache；
- 端到端吞吐、TTFT、TPOT 和尾延迟；
- 准确率、模型版本、上下文与输出长度；
- 功耗、冷却、占地、故障率与利用率；
- 编译器、算子、框架和开发者生态；
- 单位有效输出 Token 的全生命周期成本。

缺少这些条件时，峰值 PFLOPS 或单一倍数只能作为厂商规格/来源观点，不能生成跨平台投资结论。

## 推理需求与 Token 经济性

国家数据局《全国数据资源调查报告（2025年）》记录：

- 2025 年用于 AI 训练和推理的数据总量为 199.48 EB；
- 推理数据量为 101.34 EB，首次超过训练数据量；
- 由差额可推得训练数据量约 98.14 EB；
- 全年 Token 调用量约 21,100 quadrillion，即约 21,100tn。

另一项公开数据称，中国日均 Token 调用量从 2024 年初约 100bn，上升至 2025 年底 100tn，并在 2026 年 3 月底超过 140tn。课程的方向判断成立，但把 2025 年训练/推理数据标为 2026 年，把 100tn 写作 2026 年日均水平，会导致期间错配。

课程进一步讨论 Prefill（提示词处理）和 Decode（逐 Token 生成）的分离：

- Prefill 通常更受计算和输入长度约束；
- Decode 通常更受内存带宽、并发序列与 KV cache 约束；
- 分离部署可以按负载配置不同资源，但也引入 KV cache 传输、调度和网络开销；
- 是否改善成本和延迟必须由真实模型、流量、硬件、软件版本和服务等级验证。

推理量增长提高推理基础设施的研究优先级，但 Token 数量不是收入：模型压缩、蒸馏、缓存、路由、降价、硬件效率和闲置率都可能改变 Token 与芯片需求、云收入和利润之间的关系。
