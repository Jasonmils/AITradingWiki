# Ethereum 项目公开发布（2014-01-23）

## 事件摘要

2014-01-23，Vitalik Buterin 在 Ethereum Foundation 官方博客发布“Ethereum: Now Going Public”，宣布 Ethereum 项目公开，并描述白皮书初稿与团队形成过程。Ethereum.org 官方白皮书页面把白皮书标为 2014 年发布、早于项目正式启动。

本 Event 只确认项目公开与研究设计传播节点，不把 2014-01-23 认定为本地 36 页 PDF 的精确 revision 日期，也不证明主网上线、独立复现、生产部署或规模采用。`technology_maturity: research` 与 `commercialization_stage: none` 描述该事件直接支持的最高证据，而非 Ethereum 当前状态。

## 已确认事实

- 官方博文日期和署名分别为 2014-01-23 与 Vitalik Buterin。
- 博文明确把该时点描述为 Ethereum “going public”，并提及此前已经编写 initial draft。
- 官方白皮书页面将文档标记为 2014 年发布，并提醒原始白皮书已经不能准确反映当前 Ethereum。

## 技术相关性

该事件建立 Ethereum 通用区块链应用平台研究的公开节点：账户状态、EVM、Gas、smart contract、DApp、历史 PoW/GHOST 和发行模型被组织成一套公开设计。
